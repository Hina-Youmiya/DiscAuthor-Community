# DiscAuthor Community 0.4.17

Native SwiftUI DVD-Video / Blu-ray authoring for Apple Silicon Macs, with a Python authoring engine. The interface defaults to Japanese and also supports Chinese and English.

**Status: GPL source preview.** Original application code is licensed under **GNU GPL version 3 (GPL-3.0-only)**; see [LICENSE](LICENSE). Third-party components keep their own licenses; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The 0.4.16 Community application bundle was built and tested on the preparation Mac. Its packaged backend passed four synthetic ISO export cases: DVD with a menu, DVD with one video and no menu, Blu-ray with a menu, and Blu-ray with one video and no menu. Two actual native GUI startup and shutdown regression runs passed, with no backend left running after exit. A limited native UI/playback smoke test also passed: the default Japanese interface worked, DVD and BD menu ISOs displayed their menus, and direction/confirm actions started moving test footage. The BD menu's white text changed to yellow for focus and followed Down navigation. Installation and operation on a clean second Mac have not been verified.

Version 0.4.17 adds the missing DVD Title/Top Menu entry and a Blu-ray Popup Menu return path during movie playback. The return route preserves the originating menu page and programme selection. See [menu-return changes and validation](docs/MENU_RETURN.md) for the distinct remote commands, test procedure and limits. Previously exported ISOs and burned discs are not changed by an application update.

## Features retained

- Generic menus with automatic or custom layout, local fonts, text/outline colors, remote-control navigation and button feedback.
- DVD-Video and HDMV Blu-ray ISO authoring with menus; single-video, no-menu mode stops after playback.
- Queue, progress, export-to-burn handoff, optical drive controls and optional burn-data verification.
- Native optical-disc playback using a separately prepared VLC runtime.

Company-specific artwork, templates, proprietary fonts, customer projects, source videos and delivered ISO files are excluded. Projects requiring private templates are rejected explicitly. Community preferences and project data use a separate location, `~/Library/Application Support/DiscAuthor Community`.

## Requirements and build

The current build target is **Apple Silicon, macOS 15 or later**. There is no validated Intel, Windows or Linux application. Building requires the Apple command-line developer tools and Python 3.12 or later; requirements-build.txt supplies CMake and the Python build dependencies. The source checkout contains the build recipes; the application bundle contains its prepared runtime tools.

Read [BUILD.md](docs/BUILD.md) for the complete build and packaging commands, [DEPENDENCIES.md](docs/DEPENDENCIES.md) for upstream inputs and audit boundaries, and [SIGNING.md](docs/SIGNING.md) for optional Developer ID signing and notarization. The current free route uses ad-hoc signing and does not require a paid Apple certificate; see [installation](docs/INSTALL_UNSIGNED.md). A complete application bundle does not require users to install Python, Homebrew or an encoder separately.

## Known limits

**Panasonic DMP-BD65 has rejected discs generated by this application, including menu and no-menu releases. This remains unresolved.** Discs from earlier builds were reported playable on a Panasonic DMP-BDT180; Community 0.4.16 has not been physically verified. Software parsing, ISO verification and byte-for-byte burn verification do not establish compatibility with every physical player. This preview must not be advertised as production-ready Blu-ray delivery software.

Protected commercial discs and BD-J playback are not guaranteed. Burning is available only through macOS-compatible optical drives. The four backend export tests did not burn discs and do not replace full visual, clean-Mac or physical-player testing.
